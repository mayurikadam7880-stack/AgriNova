# Smart Agriculture AI

## About

Smart Agriculture AI is a web-based application that helps identify crop diseases using AI and provides live weather information.

## Features

- User Signup and Login
- Crop Disease Detection
- AI Confidence Score
- Disease Recommendation
- Live Weather Dashboard
- SQLite Database

## Technologies

- Python
- Flask
- HTML
- CSS
- JavaScript
- TensorFlow
- Keras
- SQLite
- OpenWeather API
